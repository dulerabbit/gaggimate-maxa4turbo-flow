# Discord blurb (copy/paste)

Community Digmesa measured-flow controller build (not official GaggiMate):

**Web flasher (Chrome/Edge):** https://dulerabbit.github.io/gaggimate-maxa4turbo-flow/  
**Repo / releases:** https://github.com/dulerabbit/gaggimate-maxa4turbo-flow

1. Open the flasher in Chrome → Connect Pro → Install (**controller only**, leave display alone)
2. Wire Digmesa signal → **EXT4 (GPIO12)** + pull-up to 3.3V (not IO14, not Velofuso TCA IO2)
3. FLOW mode = PI on measured ml/s; pressure target is still the ceiling
